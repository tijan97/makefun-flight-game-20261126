Sky Courier: Ridge Run — a chase-view bush-plane courier game. Fly the Kestrel mail plane through glowing rings over Pinefield Valley, follow the river to Lakeside Strip, cross the Highpass ridge, and land on three mountain airstrips without running out of fuel. Original 2D canvas game, plain JavaScript, no engine, no network requests, synthesised WebAudio engine and wind sounds.

## Run it

```sh
python3 -m http.server 8000
```

Then open http://localhost:8000/game/ in a desktop browser. Steer with Arrow keys / WASD, Shift to throttle up, Space to brake, P to pause, M to mute. Hold the mouse button to steer toward the cursor.
